# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly:

- Open a [private security advisory](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
  on this repository, or
- Contact the maintainers directly rather than opening a public issue.

Please do not disclose security vulnerabilities publicly (including in
public GitHub issues or discussions) until they have been reviewed and
addressed.

We will do our best to acknowledge reports promptly and keep you informed
as a fix is developed.
